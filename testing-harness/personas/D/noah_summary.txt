The interviewee, Alex Johnson, is an Academic Process Coordinator responsible for managing student processes, student ticket management, and the computer repair workflow within the university's administrative department. Alex confirmed that these are the main processes they handle regularly.

For student ticket management, the process begins when a student opens a ticket in Sipac, which takes about 10 minutes. The CRA then opens the process in Sipac and forwards it for checking any pending issues, a manual process that takes about 30 minutes. Alex handles notifying the student about any pending issues via email. If documents are missing, this can cause delays as the process stalls until the student resubmits the necessary documents. After notifying the student, Alex enters the information into the academic system, which takes about 20 minutes, and then notifies approval via email. The main bottleneck is when students fail to provide necessary documents, causing delays. If the student does not respond, the ticket remains stalled, and Alex may need to follow up.

In the computer repair workflow, Alex starts by providing a repair cost calculation, which takes about 45 minutes. The repair technician then checks and repairs the hardware using diagnostic tools, taking about 2 hours, before passing it to the software technician. The software technician checks and configures the software using configuration software, taking about 1.5 hours, and then it moves to quality assurance. Quality assurance tests the system functionality using testing software, taking about an hour, before it goes to the billing department. The billing department handles billing using billing software, taking about 30 minutes, and then customer service returns the repaired computer. A common issue is unexpected hardware failure during testing, which can increase repair time and require cost adjustments.
